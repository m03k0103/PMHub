# 政策会議ウォッチ (Policy Meeting Hub - pm-hub)

> 日本の**全21省庁・内閣官房・内閣府・独立委員会**に分散している審議会・諮問会議・分科会・検討会等の更新情報や配布資料を一箇所に集約し、一般国民・報道関係者（記者）・研究者向けに高度な一覧性と分析機能を提供するオープン情報ポータル

---

## 📂 ディレクトリ構成・リソース分離

本プロジェクトは、一般利用者がアクセスする **「一般公開用リソース (`public/`)」** と、システム運用者が利用する **「管理者向けリソース (`admin/`)」**、および **「ドキュメント (`docs/`)」** にフォルダ・ファイルを明確に分離して管理しています。

```
PMHub/
├── public/                      # 【一般公開用】エンドユーザー向けポータルWebアプリケーション
│   ├── index.html               # 公開ポータルメインHTML構造・UIレイアウト
│   ├── styles.css               # 全21省庁対応デザインシステム・CSSスタイル
│   ├── data.js                  # 審議会・会議配布資料データベース (構造化オブジェクト)
│   └── app.js                   # フロントエンドSPAロジック (検索・フィルター・エクスポート・要約ON/OFF)
│
├── admin/                       # 【管理者向け】データ自動更新・システム運用管理ツール
│   ├── crawler.py               # 政府Webサイト自動巡回・PDF解析Pythonクローラー
│   ├── scraped_councils_output.json # クローラー最新自動取得ログ・抽出JSONデータ
│   └── admin_guide.md           # 管理者用 運用マニュアル・Cron/タスクスケジューラ設定ガイド
│
├── docs/                        # 【全般ドキュメント】プロジェクト構成・役割説明書
│   └── RESOURCE_MAP.md          # リソースファイル役割構成・セキュリティ管理説明書
│
└── README.md                    # 本ドキュメント (総合ガイド)
```

各リソースファイルの詳しい役割定義・権限区分については [docs/RESOURCE_MAP.md](file:///d:/dev/PMHub/docs/RESOURCE_MAP.md) をご覧ください。

## 🌟 カバーする全21省庁・内閣官房・行政機関

- **内閣官房 (CAS)**: 全世代型社会保障構築会議、社会保障国民会議、中東情勢に関する関係閣僚会議 等
- **内閣府 (CAO)**: 人工知能戦略本部、AI戦略会議、規制改革推進会議 等
- **デジタル庁 (Digital)**: デジタル社会推進会議、データ戦略検討会 等
- **こども家庭庁 (CFA)**, **復興庁 (RA)**, **総務省 (MIC)**, **法務省 (MOJ)**, **外務省 (MOFA)**, **財務省 (MOF)**, **文部科学省 (MEXT)**, **厚生労働省 (MHLW)**, **農林水産省 (MAFF)**, **経済産業省 (METI)**, **国土交通省 (MLIT)**, **環境省 (MOE)**, **防衛省 (MOD)**, **警察庁 (NPA)**, **金融庁 (FSA)**, **消費者庁 (CAA)**, **個人情報保護委員会 (PPC)**, **公正取引委員会 (FTC)**, **原子力規制委員会 (NRA)**

## 💻 閲覧・起動方法

### 一般公開ポータルの閲覧
`public/index.html` をお持ちのブラウザで直接開くことで、ビルド不要で即座に動作確認できます。

```bash
# Python による簡易Webサーバー起動例 (public/ ディレクトリを公開)
cd public
python -m http.server 8000
# http://localhost:8000 にアクセス
```

### 管理者向けクローラーの実行
```bash
cd admin
python crawler.py
```
